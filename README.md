# 🐶 わんわん ぴょこぴょこ

飼っている犬の写真を切り抜いて、アニメ調の動きでループ再生する Web アプリです。
1歳半のお子さんが画面をさわっても止まらない・切り替わらないように作ってあります。

- **写真はスマホの中だけで処理されます。**どのサーバーにも送られません。
- ビルド（変換作業）は不要です。ファイルを置くだけで動きます。
- インターネットは、AI（切り抜き機能）を最初に読みこむときだけ使います。

---

## 1. いま作ってあるもの（第1段階 ✅ 完成）

1. 写真をえらぶ（スマホのカメラロールから）
2. 犬をタップすると自動で切り抜く（うまくいかないときは指でなぞって修正）
3. 「ぴょこぴょこ」を全画面でループ再生
4. 再生中はさわっても止まらない／画面が切り替わらない
5. さわると犬が大きくはねて、キラキラが出る
6. おわるのは「右上のボタンを **2.5秒ながおし**」だけ（大人しかできない操作）

---

## 2. スマホで試す手順

タブレット／スマホのブラウザだけで完結します。パソコンは不要です。

### ステップ1：GitHub Pages を有効にする（最初の1回だけ）

1. ブラウザで `github.com` を開き、リポジトリ **hanachata87-lgtm/dog-animation** を開く
2. 上のメニューの **Settings**（歯車マーク／設定）をタップ
   - メニューが見つからないときは、画面が狭いので「…」を押すと出てきます
3. 左のリストから **Pages** をタップ
4. **Source**（ソース）を `Deploy from a branch` にする
5. **Branch**（ブランチ）で `claude/dog-photo-animation-app-rf8d0w` をえらび、右のフォルダは `/ (root)` のままにする
6. **Save**（保存）をタップ

> 💡 リポジトリが **Private（非公開）** だと、無料プランでは Pages が使えません。
> その場合は Settings のいちばん下 → `Change repository visibility` → **Public** に変えてください。
> （写真はアップロードされないので、公開しても写真が見られることはありません）

### ステップ2：1〜2分待ってから開く

Pages の画面に出てくるアドレス、または下の URL をスマホのブラウザで開きます。

```
https://hanachata87-lgtm.github.io/dog-animation/
```

最初は「404」と出ることがあります。1〜2分おいて、ページを **下に引っぱって再読みこみ** してください。

### ステップ3：ホーム画面に置く（おすすめ）

Chrome のメニュー（右上の「⋮」）→ **ホーム画面に追加**。
アプリのように全画面で開くので、お子さんが他の画面に行きにくくなります。

### ステップ4：遊んでみる

1. **［写真をえらぶ］** → カメラロールから犬の写真をえらぶ
2. 「AIの準備中…」と出ます。**はじめの1回だけ10〜30秒かかります**（次からは速いです）
3. **犬のからだのまん中あたりを1回タップ** → 明るくなったところが切り抜かれる部分です
4. はみ出していたら **［🧽 けす］**、足りなければ **［✏️ たす］** を選んで指でなぞる（**［↩️ もどす］** でやり直せます）
5. **［これでOK →］** → 動きと はやさ をえらぶ
6. **［▶ ぜんがめんで あそぶ］** → ループ再生がはじまります
7. おわるときは **右上のうすいボタンを 2.5秒 ながおし**

## 3. 全体の段階計画

| 段階 | 内容 | 状態 |
|---|---|---|
| **第1段階** | 写真を入れる → タップで切り抜く → ぴょこぴょこループ → さわっても止まらない | ✅ 完成 |
| **第2段階** | 「顔だけ / 全身」の選択、**いないいないばあ**（肉球の手で顔をかくして「ばあ」） | これから |
| **第3段階** | **しっぽふりふり・おてふり**（ゆらす部分をタップで指定）、**おまかせ**（ランダム）、お気に入り保存 | これから |
| **第4段階** | **書き出し**（静止画PNG／LINEアニメーションスタンプ用APNG：320×270px以内・4秒以内・ループ1〜4回） | これから |
| **第5段階** | 仕上げ（動作を軽くする、オフラインでも開けるようにする、細かい調整） | これから |

段階ごとに区切ってあるので、第1段階を実際に娘さんに見せてみて、
「動きが速すぎる」「もっと大きく跳ねてほしい」などの感想をもとに次に進めます。

## 4. 気をつけること・うまくいかないとき

| こまったこと | どうするか |
|---|---|
| 「じどう切り抜きの準備ができませんでした」と出る | 通信が弱いところで起きます。Wi-Fi のある場所でページを再読みこみしてください。そのままでも **［✏️ たす］の ふで で犬をぬれば** 遊べます |
| 切り抜きが犬以外まで選ばれる | 犬の **胴体のまん中** をタップし直してください。それでもだめなら「けす」で削ります |
| 切り抜きの形がガタガタ | ふでの太さを細くして「たす」「けす」で整えてください |
| 再生をやめられない | 右上のうすい丸ボタンを、**指をはなさずに2.5秒** 押し続けてください（白い輪が1周したら終わります） |
| 動きがカクつく | 写真は自動で小さくされますが、他のアプリを閉じるとなめらかになります |

**おすすめの写真**：明るい場所で、犬と背景の色がはっきり違い、犬が大きく写っているもの。

## 5. ファイルの中身（開発メモ）

```
index.html      画面のかたち（4つの画面：さいしょ / 切り抜き / 動きえらび / 再生）
styles.css      見た目
js/main.js      画面のつなぎ役。写真の読みこみ、ふで、画面のきりかえ
js/segmenter.js MediaPipe Interactive Image Segmenter（Magic Touch）のラッパー
js/cutout.js    マスクの操作（連結部分の抽出・ふで・ふちの処理・透過PNG化）
js/motions.js   動きの定義。新しい動きはここに足すだけで増やせる
js/player.js    全画面ループ再生と子どもロック
```

技術的なメモ：

- モデルと WASM は jsDelivr / Google の CDN から読みこみ、**推論はすべて端末内**で行います
- 写真は長辺 1024px に縮めてから処理し、スマホでも軽く動くようにしています
- 子どもロックは「`touch-action:none`／`preventDefault`／`popstate` で戻るを無効化／全画面／Wake Lock」の組み合わせです
- 前回の切り抜きは `localStorage` にこの端末だけで保存され、次に開くと［まえのわんちゃんで あそぶ］が出ます
