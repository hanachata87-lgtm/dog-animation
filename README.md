# 🐾 ぴょこぴょこ うごかそう

写真を切り抜いて、アニメ調の動きでループ再生する Web アプリです。
**犬でも ねこでも 人の顔でも**、切り抜けるものなら なんでも動かせます。
1歳半のお子さんが画面をさわっても止まらない・切り替わらないように作ってあります。

- **写真はスマホの中だけで処理されます。**どのサーバーにも送られません。
- ビルド（変換作業）は不要です。ファイルを置くだけで動きます。
- インターネットは、AI（切り抜き機能）を最初に読みこむときだけ使います。

---

## 1. いま作ってあるもの（第1〜第3・第5段階 ✅ 完成）

1. 写真をえらぶ（スマホのカメラロールから）
2. 犬をタップすると自動で切り抜く（うまくいかないときは指でなぞって修正）
3. **どこを使うかをえらぶ**
   - **🐕 ぜんしん**：写真の犬をそのまま動かす
   - **😀 かおだけ**：顔に丸を合わせて切り出す
   - **🕺 かおだけ＋イラストの体**：犬の顔に、マンガの体（シャツ・ズボン・肉球の手足）がつく
4. 動きをえらぶ
   | 動き | 使える写真 | どんな動き |
   |---|---|---|
   | **ぴょこぴょこ** | ぜんぶ | のびちぢみしながら ぴょんぴょんはねる |
   | **ふりふり** | ぜんしん / かおだけ | **タップしたところ**（しっぽ・手・耳など）だけが ゆれる |
   | **くるくる** | ぜんぶ | ぐるっと まわりながら ふわふわ うかぶ |
   | **ぷるぷる** | ぜんぶ | こまかく ぶるぶる ふるえる |
   | **ゆらゆら** | ぜんぶ | ゆっくり 左右にかたむく（おちつく動き） |
   | **おおきく ちいさく** | ぜんぶ | ふくらんだり しぼんだり |
   | **いないいないばあ** | かおだけ | まるい手が顔をかくして「ばあ！」 |
   | **いないいないばあ（体つき）** | 体つき | 自分の手で顔をかくして、ばんざいで「ばあ！」 |
   | **ウェーイ！** | 体つき | うでを ななめ上に つき上げて へんてこダンス |
   | **ばんざい** | 体つき | 両手を上げて ジャンプ |
   | **おいでおいで** | 体つき | 片手を ふりふり |
   | **🎲 おまかせ** | ぜんぶ | **10秒ぐらいごとに ひとりでに 変わりつづける**（いちばんのおすすめ） |

5. **どこを動きまわるかをえらぶ**（どの動きとも組み合わせられます）
   | 動きまわりかた | どうなる |
   |---|---|
   | **その場** | まん中でじっとしたまま動く |
   | **🏃 走ってく** | 右から左へバーッと走って画面から消え、つぎは反対がわから出てくる |
   | **🏀 スーパーボール** | 画面じゅうを あちこち 跳ねまわる（跳ぶ高さも向きも毎回ちがう） |
   | **🎲 おまかせ** | 押すたびに変わる |

   > 動きを「🎲 おまかせ」にしたときは、動きまわりかたと はやさも ひとりでに決まります。
6. **さわったら どうなるか**をえらぶ
   | | どうなる |
   |---|---|
   | **🐾 おともだちが ふえる**（はじめはこれ） | さわったところに 切り抜いたものが出てきて、さわるほど どんどん増える |
   | **✨ キラキラが でる** | さわったところに キラキラが とびちる |
   | **✨🐶 りょうほう** | 両方でる |
7. **はやさ**をえらぶ（とってもゆっくり／ゆっくり／ふつう／はやい）
8. 全画面でループ再生
9. **⭐ おきにいり**に保存すると、次からは最初の画面からすぐ遊べる（6個まで）
10. 再生中はさわっても止まらない／画面が切り替わらない
11. さわると犬が大きくはねる（＋えらんだ反応が出る）
12. おわるのは「右上のボタンを **2.5秒ながおし**」だけ（大人しかできない操作）

> 💡 動きをえらぶと、**その動きに合った動きまわりかたが自動でえらばれます**。
> （ウェーイ！→ 走ってく、ぴょこぴょこ → スーパーボール、いないいないばあ → その場）
> あとから自由に変えられます。

## 2. スマホで試す手順

タブレット／スマホのブラウザだけで完結します。パソコンは不要です。

### ステップ1：GitHub Pages を有効にする（最初の1回だけ）

1. ブラウザで `github.com` を開き、リポジトリ **hanachata87-lgtm/dog-animation** を開く
2. 上のメニューの **Settings**（歯車マーク／設定）をタップ
   - メニューが見つからないときは、画面が狭いので「…」を押すと出てきます
3. 左のリストから **Pages** をタップ
4. **Source**（ソース）を `Deploy from a branch` にする
5. **Branch**（ブランチ）で `claude/dog-photo-animation-app-rf8d0w` をえらび、右のフォルダは `/ (root)` のままにする
6. **Save**（保存）をタップ

> 💡 リポジトリが **Private（非公開）** だと、無料プランでは Pages が使えません。
> その場合は Settings のいちばん下 → `Change repository visibility` → **Public** に変えてください。
> （写真はアップロードされないので、公開しても写真が見られることはありません）

### ステップ2：1〜2分待ってから開く

Pages の画面に出てくるアドレス、または下の URL をスマホのブラウザで開きます。

```
https://hanachata87-lgtm.github.io/dog-animation/
```

最初は「404」と出ることがあります。1〜2分おいて、ページを **下に引っぱって再読みこみ** してください。

### ステップ3：ホーム画面に置く（おすすめ）

Chrome のメニュー（右上の「⋮」）→ **ホーム画面に追加**。
アプリのように全画面で開くので、お子さんが他の画面に行きにくくなります。

### ステップ4：遊んでみる

1. **［写真をえらぶ］** → カメラロールから写真をえらぶ（犬・ねこ・人の顔など なんでも）
2. 「AIの準備中…」と出ます。**はじめの1回だけ10〜30秒かかります**（次からは速いです）
3. **うごかしたいものの まん中あたりを1回タップ** → 明るくなったところが切り抜かれる部分です
4. はみ出していたら **［🧽 けす］**、足りなければ **［✏️ たす］** を選んで指でなぞる（**［↩️ もどす］** でやり直せます）
5. **［これでOK →］** → **［🐕 ぜんしん］／［😀 かおだけ］／［🕺 かおだけ＋イラストの体］** をえらぶ
6. かおを使うときは、**白い丸を指で動かして犬の顔に合わせ**、下のスライダーで大きさを調整 →［これでOK →］
7. 動き・動きまわりかた・さわったときの反応・はやさ をえらぶ
8. **［▶ ぜんがめんで あそぶ］**
   - ふりふりのときは、**ゆらす場所をタップする画面**が出ます。
     しっぽ・手・耳などをタップして、丸の広さを合わせて［これでOK →］を押すと、そのまま再生がはじまります

> 👶 **長く遊ばせたいとき**は、動きを **［🎲 おまかせ］** にして渡してください。
> 10秒ぐらいごとに 動き・動きまわりかた・はやさが ひとりでに変わりつづけるので、
> ずっと同じ動きを見つづけて飽きる、ということが起きにくくなります。
9. 気に入ったら **［⭐ おきにいりに 入れる］**
10. おわるときは **右上のうすいボタンを 2.5秒 ながおし**

## 4. キーボードや スワイプで 画面が変わってしまうとき

キーボード付きタブレットで遊ばせると、子どもが興奮してキーを連打したり、
画面のはしを指ではらったりして、別の画面に飛んでしまうことがあります。

### アプリの中でやっていること（第5段階 ✅）

- 再生中は **キーボードの入力をすべて止めます**（打っても何も起きません）
- **「もどる」が起きたら自動で押しもどします。** 連打されても足りるよう、
  再生をはじめた時点で15回ぶんの履歴を用意し、1回もどられるたびに3回ぶん つぎたします
- 画面のはしからのスワイプ・ピンチ・引っぱって更新・長おしメニューを止めます
- 全画面表示にし、画面が消えないようにします
- まちがえてページを閉じようとすると、ブラウザが確認をたずねます
  （※大人が閉じたいときは「このページを離れる」を選んでください）
- **ホーム画面に追加すると全画面アプリとして開きます**（アドレスバーやタブが消えます）

### ただし、これだけは止められません

キーボードのショートカットで **電卓などが立ち上がるのは、タブレット本体（Android）の動き**です。
画面のいちばん上から下へはらったときに出る通知バーも同じで、
**ブラウザで動くアプリからは止められません。** 確実にふせぐには次のどちらかをお使いください。

### ① キーボードを外す（いちばん確実）

着脱式のカバーなら外す。Bluetoothキーボードなら「設定 → 接続済みのデバイス」から接続を切ります。

### ② Androidの「アプリ固定（画面の固定）」を使う

1. 設定 → セキュリティとプライバシー →（その他のセキュリティ設定）→ **アプリ固定**
   ※機種により「画面の固定」という名前です
2. ONにする（「固定を解除する前にPINを要求」もONにすると、より安全です）
3. このアプリを開く
4. 最近使ったアプリの画面を出す（□ボタン、またはジェスチャー操作なら画面の下から上にスワイプして指を止める）
5. このアプリのアイコンをタップ → **「固定」** をえらぶ

固定中はほかのアプリに切りかわらないので、キーボードをたたいても電卓は出ません。
解除は「もどる」と「ホーム」を同時に長おし（ジェスチャー操作なら、画面の下から上にスワイプして長おし）です。

> この手順はアプリの最初の画面の「おうちのかたへ」にも書いてあります。

## 5. 気をつけること・うまくいかないとき

| こまったこと | どうするか |
|---|---|
| 「じどう切り抜きの準備ができませんでした」と出る | 通信が弱いところで起きます。Wi-Fi のある場所でページを再読みこみしてください。そのままでも **［✏️ たす］の ふで で犬をぬれば** 遊べます |
| 切り抜きが犬以外まで選ばれる | 犬の **胴体のまん中** をタップし直してください。それでもだめなら「けす」で削ります |
| 切り抜きの形がガタガタ | ふでの太さを細くして「たす」「けす」で整えてください |
| 再生をやめられない | 右上のうすい丸ボタンを、**指をはなさずに2.5秒** 押し続けてください（白い輪が1周したら終わります） |
| 動きがカクつく | 写真は自動で小さくされますが、他のアプリを閉じるとなめらかになります |
| 走るときに 犬が うしろ向きに見える | 走る向きに合わせて絵を左右反転しています。元の写真の向きによっては、片方の向きだけ不自然に見えます。気になるときは「その場」か「スーパーボール」をおえらびください |
| すぐ飽きてしまう | 「🎲 おまかせ」にすると、10秒ぐらいごとに 動き・動きまわりかた・はやさが ひとりでに 変わりつづけます。「🐾 おともだちが ふえる」にすると、さわるたびに画面がにぎやかになります |
| 動きが速すぎる／おそすぎる | はやさは4だんかいあります。「ふつう」でも速いときは「ゆっくり」「とってもゆっくり」をおためしください。**走る・跳ねまわる速さも、このはやさに合わせて変わります** |
| 大人がページを閉じたい | 再生中は「このページを離れますか？」と聞かれます。**先に右上を2.5秒長おしして再生を終えてから**閉じると聞かれません |
| おともだちが 増えすぎた | 40ひきをこえると 古いものから消えます。いちど終わって もう一度あそぶと、まっさらにもどります |
| 「いないいないばあ」が えらべない | 「かおだけ」でつくった写真のときだけ出ます。［もどる］で「どこを つかう？」まで戻って［😀 かおだけ］をえらんでください |
| 動きが多くて えらぶのが めんどう | **［🎲 おまかせ］**をえらべば、あとは全部ひとりでに決まります |
| 顔の丸が うまく合わない | 丸は **指でタップした場所が中心** になります。大きさは下のスライダーで変えられます。少し大きめにとると、耳まで入ってかわいくなります |
| しっぽのゆれ方が いまいち | ゆらす丸を **小さめ**にすると先だけがちょろちょろ、**大きめ**にするとどっしり揺れます。付け根は体の中心に近いがわに自動で決まります |
| おきにいりを けしたい | 最初の画面で、けしたいおきにいりを **長おし**してください（子どもが誤って消さないように長おしにしています） |
| おきにいりが 保存できない | 端末のあきがないときに出ます。古いおきにいりを消してからもう一度おためしください |

**おすすめの写真**：明るい場所で、犬と背景の色がはっきり違い、犬が大きく写っているもの。

## 6. ファイルの中身（開発メモ）

```
manifest.webmanifest  ホーム画面に追加したとき 全画面アプリとして開くための設定
icon-192.png / icon-512.png / icon.svg  アプリのアイコン
index.html      画面のかたち（4つの画面：さいしょ / 切り抜き / 動きえらび / 再生）
styles.css      見た目
js/main.js      画面のつなぎ役。写真の読みこみ、ふで、画面のきりかえ
js/segmenter.js MediaPipe Interactive Image Segmenter（Magic Touch）のラッパー
js/cutout.js    マスクの操作（連結部分の抽出・ふで・ふちの処理・透過PNG化）
js/motions.js   動きの定義。新しい動きはここに足すだけで増やせる
js/paw.js       イラストの肉球の手（画像ファイル不要。すべて図形で描いている）
js/body.js      イラストの体。うで・あしは2本の骨で、手先の位置から角度を逆算している
js/wiggle.js    しっぽ・前足だけをゆらすしくみ（丸く切りとって 付け根を軸に回す）
js/travel.js    画面のどこを動きまわるか（走る／スーパーボールの跳ねかた）
js/player.js    全画面ループ再生と子どもロック
```

技術的なメモ：

- モデルと WASM は jsDelivr / Google の CDN から読みこみ、**推論はすべて端末内**で行います
- 写真は長辺 1024px に縮めてから処理し、スマホでも軽く動くようにしています
- 子どもロックは「`touch-action:none`／`preventDefault`／`popstate` で戻るを無効化／全画面／Wake Lock」の組み合わせです
- 動きは `anchor`（地面に立つ／まん中に浮かぶ）・`overlay`（絵の上に重ねる描画）・
  `rig`（イラストの体のかっこう）・`wiggle`（一部分だけゆらす角度）・
  `defaultTravel`（おすすめの動きまわりかた）をもてる形にしてあり、
  新しい動きは `js/motions.js` に1つ足すだけで増やせます
- 「おまかせ」は player 側でまわしています。1周ぶんの切れ目にそろえて 9〜16秒ごとに
  つぎの組み合わせへ切りかえ、おなじ動きが2回つづかないようにしています
- 「動きまわりかた」は動きとは別の部品（`js/travel.js`）なので、
  どの動き × どの動きまわりかた でも組み合わせられます
- はやさの倍率は、動きだけでなく 走る速さ・跳ねまわる速さにもかかります
  （travel の中で 時間の進みかたを その倍率で割っています）
- イラストの体は、うで・あしを2本の骨とみなし、手先の位置から角度を逆算（2関節IK）しています。
  「顔をかくす」「ばんざい」などは手先の目標位置を書くだけで、うでが自然に曲がります
- 「かおだけ」は切り抜き画像を丸く切り出したもので、ふちだけ少しぼかして首の切れ目を目立たなくしています
- 前回の切り抜きは `localStorage` にこの端末だけで保存され、次に開くと［まえのつづきから あそぶ］が出ます
